💠 _три_ раздела главного меню, из каждого можно вернуть в корень:

**📶 подключение** - если подключение есть, показывает ключ и все данные по подключению, если его нет предлагает одной кнопкой подключить тестовый период на три дня -> идет обновление сообщения, а дальше сами понимаете. если у пользователя уже было подключение, которое истекло, то кидаем инфу об этом и ссылку на личный кабинет. 

**👤 личный кабинет** - выводит информацию о пользователе и текущем тарифе (в формате есть тариф: один текст (мб кнопка "пригласить друга" + КНОПКА ДЛЯ ИНФОРМАЦИИ ОБ ОПЕРАЦИЯХ с балансом + КНОПКА ДЛЯ ЗАЧИСЛЕНИЯ ДЕНЕГ НА СЧЕТ), нет тарифа: другой текст (мб кнопка "пригласить друга", + кнопка для выбора тарифа с последующей оплатой + КНОПКА ДЛЯ ЗАЧИСЛЕНИЯ ДЕНЕГ НА СЧЕТ + КНОПКА ДЛЯ ИНФОРМАЦИИ ОБ ОПЕРАЦИЯХ с балансом))
